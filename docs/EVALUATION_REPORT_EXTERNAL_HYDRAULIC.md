# External Evaluation Report — Hydraulic Systems (UCI #447)

Track B external benchmark. This report documents an independent, deterministic evaluation of the hydraulic-systems condition-monitoring dataset. It is generated by `scripts/run_hydraulic_benchmark.py`.

## Scope and disclaimers

- **Not a root-cause-analysis (RCA) result.** This benchmark classifies
  component condition codes; it does not diagnose failure causes, recommend
  work orders, or propose maintenance actions.
- **No work-order or CMMS integration.** No work orders are generated, and
  nothing is written to any maintenance system.
- **Not field deployment.** Results are offline benchmark scores on a public
  dataset and must not be read as production or on-rig performance.
- **Narrow estimand.** Results measure complete-profile-group-held-out
  interpolation for stable cycles from one laboratory rig, not unseen assets,
  rigs, future time periods, transient operation, or operating domains.
- **Uncalibrated scores.** All metrics are computed from hard class
  predictions; model decision outputs are not calibrated probability
  estimates and must not be interpreted as such.

## Dataset

- Name: `condition-monitoring-of-hydraulic-systems`
- Source: [https://archive.ics.uci.edu/static/public/447/condition+monitoring+of+hydraulic+systems.zip](https://archive.ics.uci.edu/static/public/447/condition+monitoring+of+hydraulic+systems.zip)
- SHA-256: `24128aad2ee45eea7e6b63ebbd9992cdf25d0483a2cebefbfc13bc69079af1f2`
- Cycles: 2205 total; 1449 stable (primary benchmark subset)
- Stable-only scope: 756 non-steady cycles are excluded because their official
  flag says static conditions might not have been reached; reported performance
  therefore does not cover start-up or transition behavior.
- Sensors (primary benchmark): PS1-6, EPS1 (100 Hz / 6000 samples), FS1-2 (10 Hz / 600 samples), TS1-4, VS1 (1 Hz / 60 samples); CE/CP/SE excluded as derived target-proxy controls.
- Targets: cooler (3 classes) and valve (4 classes).

## Methodology

- **Features:** per-sensor mean, std (population, ddof=0), min, max over the
  stable cycle window → 14 sensors × 4 = 56 features.
- **Split:** complete-profile groups `(cooler, valve, pump, accumulator)` are
  partitioned into train/val/test with no group or cycle overlap, targeting
  ~60/20/20, with every target class represented in every set (deterministic;
  no random-cycle fallback).
  This is not a chronological split; temporal autocorrelation within the rig may
  remain, so the result is described as group-held-out interpolation.
- **Models:** fixed-hyperparameter sklearn pipelines.
  - Logistic: SimpleImputer(median) → StandardScaler → LogisticRegression(max_iter=2000, class_weight='balanced').
  - Random forest: SimpleImputer(median) → RandomForestClassifier(n_estimators=300, class_weight='balanced_subsample').
- **Selection:** preferred family per target = highest validation macro-F1;
  test results for **both** families are reported untouched.
- **Seed:** 447 (models), 447 (split).
